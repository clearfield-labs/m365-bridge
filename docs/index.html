Install M365 Bridge

Microsoft 365 for Claude. Takes about two minutes, once.

  1. Copy the install command.
    curl -fsSL https://raw.githubusercontent.com/clearfield-labs/m365-bridge/main/install.sh | bash
  2. Open Terminal. Press ⌘ Space, type Terminal, press Enter.
  3. Paste and run. Press ⌘ V, then Enter. If it asks for your Mac password, type it (nothing shows while you type) and press Enter.

    If it says Node.js is missing, install it from nodejs.org (the LTS button), then run the command again.

  4. Finish in your browser. M365 Bridge opens by itself. Paste your setup code, click Sign in with Microsoft, then restart Claude.
  1. Copy the install command.
    irm https://raw.githubusercontent.com/clearfield-labs/m365-bridge/main/install.ps1 | iex
  2. Open PowerShell. Click Start, type PowerShell, press Enter.
  3. Paste and run. Right-click inside the window to paste, then press Enter. If Windows asks to install Node.js or Git, click Yes.
  4. Finish in your browser. M365 Bridge opens by itself. Paste your setup code, click Sign in with Microsoft, then restart Claude.

  1. Your setup code

    You'll paste this in step 4.

Afterwards, open M365 Bridge any time from the M365 Bridge app (Mac: ⌘ Space, type M365) or the Start menu (Windows).
